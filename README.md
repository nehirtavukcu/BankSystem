# Bank Management System

A desktop banking application developed using Java Swing and MySQL.
The project simulates basic banking operations through a graphical
user interface and database integration.

## Features

- User registration and account creation
- User login
- PIN management
- Account type selection
- Deposit money
- Withdraw money
- Fast cash withdrawal
- Balance enquiry
- MySQL database integration
- Graphical User Interface (GUI)

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- Object-Oriented Programming (OOP)

## Application Screens

The application consists of multiple screens for different banking operations:

- **Login** – User authentication
- **Signup** – User registration
- **Signup2** – Additional user information
- **Signup3** – Account details and banking services
- **Pin** – PIN management
- **Deposit** – Deposit money into the account
- **Withdrawal** – Withdraw money from the account
- **FastCash** – Quick withdrawal using predefined amounts
- **BalanceEnquiry** – Check the current account balance

## Database

MySQL is used to store and manage user and banking information.
The Java application connects to the database using JDBC.

> Before running the project, configure the database connection
> with your own MySQL credentials.

## How to Run

1. Install Java JDK.
2. Install MySQL.
3. Create the required database and tables.
4. Configure the database connection in `Connect.java`.
5. Open the project in an IDE such as IntelliJ IDEA.
6. Run the main class.
